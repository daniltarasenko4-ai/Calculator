Simple Python Calculator
This is a clean and functional console-based calculator built with Python. It demonstrates my understanding of basic programming logic, user input handling, and conditional statements.

🇩🇪 Projektbeschreibung
Ein einfacher Taschenrechner in Python, der grundlegende mathematische Operationen ausführt. Dieses Projekt zeigt meine ersten Schritte in der Softwareentwicklung und mein Verständnis für Kontrollstrukturen (if/elif/else) und Fehlervermeidung (Division durch Null).

Features
Basic Operations: Addition, Subtraction, Multiplication, and Division.

Error Handling: Specifically checks for division by zero to prevent program crashes.

User-friendly Input: Clear prompts for numbers and operators.

Edge Case Management: Handles unknown operations with a fallback message.

Logic Overview
The program follows a structured logical path:

Collects two numbers as float to allow decimal calculations.

Requests a mathematical operator.

Evaluates the operator using a conditional block.

Includes a specific check: elif op == "/" and num2 == 0: to ensure stability.

How to Run
Make sure you have Python installed.

Download the main.py file.

Run the following command in your terminal:

Bash
python main.py
